# 四季养生 · 一周菜谱生成器

> 按当下时令自动排出一周 21 餐的营养搭配，菜市场买得到，药膳甜品一起安排。318 道菜，还能自己往里加。

**在线使用：** https://seasonal-menu-jaeyeon.pages.dev

---

## 这是什么

一个静态网页工具（单入口 `index.html`，零依赖、零后端）：
打开即按今天的日期判断季节，从 **318 道**菜里生成 7 天 21 餐的搭配方案，同时给出
营养校验、一周采购清单、药膳甜品建议，以及一个能按冰箱现有食材反查菜谱的全库检索。

不是随机抽菜。配餐受三套规则同时约束：

| 维度 | 依据 |
|---|---|
| 营养 | 《中国居民膳食指南（2022）》：蔬菜 ≥300g、深色蔬菜过半、动物性食物 120–200g、每周吃鱼 2–3 次、食材 ≥25 种/周 |
| 时令 | 每道菜标注可食季节，只排当季菜（实测 504 个菜位零非当季） |
| 养生 | 中医食性（温／凉／平）按季调配，每周自动安排 2 次药膳汤、3 次食疗加餐 |

## 六个模块

### 01 配餐参数
人数 1–6、季节（自动/春夏秋冬）、辣度、预算、餐次、吃饭的人（老人/小孩/三高/孕产）、12 类忌口。

### 02 一周菜谱 + 采购清单
7 天卡片，每餐标热量、整日蛋白与蔬菜克数、深色蔬菜占比、成本。每道菜可点开看完整做法
（用料克数 + 个／根／把生活单位、分步步骤、关键点）。采购清单按类别合并、向上取整到菜市场能买的量。

### 03 药膳汤方 · 04 甜品食疗
按季节排序，每道标注功效、适用人群、**禁忌**。比如当归生姜羊肉汤注明"体质偏热、口干便秘者不宜，孕妇需遵医嘱"。

### 05 全菜谱库（按现有主材反查）
318 道菜的全量表格，支持：

- **关键词搜索**：菜名或食材
- **类别 / 时令 / 主材筛选**
- **「我有这些食材」反查**：勾选冰箱里现有的 48 种常见主料，两种模式
  - `全部具备才能做` — 精确筛选（如勾"五花肉+蒜苗"→ 回锅肉、红烧肉、梅菜扣肉、东坡肉）
  - `包含任一即可` — 宽松查找（如勾"五花肉"→ 18 道用到五花肉的菜）

点击任意一行直接看完整做法。

### 06 我的菜谱（自定义 + 同步）
表单填菜名、类别、主材、辣度、耗时、食材（每行 `名称,数量,单位,生活单位`）、步骤、关键点，
保存后**立刻进入配餐池和全菜谱库**，参与后续生成。

- 存在浏览器 localStorage，离线可用
- **导出 JSON** → 用 `tools/sync-recipes.mjs` 合并进 `data/recipes.js` 并推送到 GitHub + Gitee
- **导入 JSON** → 换设备/换浏览器时恢复

## 用量标注

每样食材同时给两种量：

```
五花肉    150 g   约 1 块掌心大
蒜苗       80 g   约 4 根
郫县豆瓣   12 g   约 1 汤匙
```

克数用于营养计算，生活单位用于菜市场估量。

## 自己加菜谱并同步到仓库

```bash
# 1. 网页「06 我的菜谱」→ 添加 → 导出 JSON，得到 recipes-custom-2026-11-25.json

# 2. 合并进仓库的数据文件
node tools/sync-recipes.mjs recipes-custom-2026-11-25.json

# 3. 确认后推送 GitHub + Gitee
node tools/sync-recipes.mjs recipes-custom-2026-11-25.json --push
```

脚本会做格式校验（缺字段、kind 非法、ing 结构错误都会拦下来），按 id 去重合并，
然后重写 `data/recipes.js`。网页下次打开自动加载，新菜就进了菜谱库和配餐池。

`data/recipes.js` 的格式很简单：

```js
window.RECIPES_EXTRA = [
  { id:'cu_蒜香排骨', name:'蒜香排骨', kind:'meat', src:'pork', spicy:1, t:40,
    veg:30, kcal:450, prot:24, dark:false, se:'all', gentle:true,
    ing:[['猪肋排',300,'g','约10小块'],['蒜',20,'g','1整头']],
    steps:['排骨泡水去血，腌 30 分钟','油六成热炸 4 分钟','复炸 30 秒'],
    tip:'复炸是酥的关键' }
];
```

## 本地使用

```bash
git clone https://gitee.com/jaeyeon/seasonal-menu.git
cd seasonal-menu
python -m http.server 8000    # 起本地服务，data/recipes.js 才能加载
```

打开 `http://localhost:8000`。直接双击 `index.html` 也能用，只是不会加载 `data/recipes.js`
（浏览器限制 file:// 下的资源加载）。

## 目录结构

```
seasonal-menu/
├── index.html              # 全部页面代码（318 道内置菜谱 + 算法 + 六个模块）
├── data/
│   └── recipes.js          # 菜谱扩充包（云端同步点，由 sync-recipes 维护）
├── tools/
│   └── sync-recipes.mjs    # 把导出的 JSON 合并进 data/recipes.js 并推送
└── seasonal-menu.pdf       # 自动生成的 PDF 样例
```

## 数据来源

- **营养标准**：中国营养学会《中国居民膳食指南（2022）》
- **价格基准**：成都农产品中心批发市场 2026-11 行情 + 成都市发改委零售监测，元/500g
- **做法参考**：《四川烹饪》及川菜师傅口诀；部分菜式结构参考 [Anduin2017/HowToCook](https://github.com/Anduin2017/HowToCook)（自行重写，非直接复制）
