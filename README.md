# 四季养生 · 一周菜谱生成器

> 按当下时令自动排出一周 21 餐的营养搭配，菜市场买得到，药膳甜品一起安排。

**在线使用：** https://seasonal-menu-jaeyeon.pages.dev

---

## 这是什么

一个单文件网页工具（`index.html`，零依赖、零外链、可离线）：
打开即按今天的日期判断季节，从 **161 道**菜里生成 7 天 21 餐的搭配方案，同时给出
营养校验、一周采购清单和药膳甜品建议。

不是随机抽菜。配餐受三套规则同时约束：

| 维度 | 依据 |
|---|---|
| 营养 | 《中国居民膳食指南（2022）》：蔬菜 ≥300g、深色蔬菜过半、动物性食物 120–200g、每周吃鱼 2–3 次、食材 ≥25 种/周 |
| 时令 | 每道菜标注可食季节，只排当季菜（实测 8904 个菜位零非当季） |
| 养生 | 中医食性（温／凉／平）按季调配，每周自动安排 2 次药膳汤、3 次食疗加餐 |

## 功能

**配餐参数**
- 用餐人数 1–6 人（克数自动缩放）
- 季节：自动判断 / 手动锁定春、夏、秋、冬
- 辣度上限：不辣 / 微辣 / 中辣 / 麻辣
- 预算档位：经济 / 标准 / 宽松
- 餐次：含早餐 / 只午晚餐
- 吃饭的人（可多选）：有老人 / 有小孩 / 三高控油 / 孕产哺乳 —— 自动换掉不适合的菜
- 忌口排除 12 类：猪肉、牛肉、羊肉、鸡鸭、鱼虾、鸡蛋、豆制品、内脏、香菜、折耳根、腌腊、辣椒

**输出结果**
- 7 天卡片，每餐标注热量、整日蛋白与蔬菜克数、深色蔬菜占比、当日成本
- 每道菜可点开看完整做法：用料（克数 + 个／根／把等生活单位）、分步步骤、关键点
- 单道菜「换一道」，从符合条件的菜里重抽
- 一周采购清单：按肉禽蛋／水产／蔬菜／豆制品／主食果奶／药膳干货／调味料分组，
  自动合并同类、向上取整到菜市场能买的量，可一键复制
- 药膳汤方与甜品食疗附录：每道标注功效、适用人群、**禁忌**
- 打印 / 存 PDF（打印样式白底黑字，配置区自动隐藏）

## 用量标注说明

每样食材同时给两种量：

```
五花肉    150 g   约 1 块掌心大
蒜苗       80 g   约 4 根
郫县豆瓣   12 g   约 1 汤匙
```

克数用于营养计算，生活单位用于菜市场估量——因为买菜时"一块肉"比"150 克"好判断。

## 本地使用

单文件，无构建、无服务端：

```bash
git clone https://gitee.com/jaeyeon/seasonal-menu.git
cd seasonal-menu
# 直接双击 index.html，或用任意静态服务器
python -m http.server 8000
```

打开 `http://localhost:8000` 即可。

## 目录结构

```
seasonal-menu/
├── index.html         # 全部代码（CSS + 161 道菜数据 + 配餐算法 + 渲染）
└── seasonal-menu.pdf  # 由 pk deploy 自动生成的 PDF（19 页）
```

`index.html` 内部分五段：菜谱数据库 → 价格表 → 配餐算法 → 渲染 → 交互。
想加菜只需往 `DB` 数组里加一条对象：

```js
{id:'xxx', name:'菜名', kind:'meat', src:'pork', spicy:2, t:25,
 veg:80, kcal:540, prot:22, dark:false, se:'au,wi', gentle:false,
 ing:[['五花肉',150,'g','约1块掌心大']],
 steps:['第一步…','第二步…'], tip:'关键点…'}
```

`se` 是时令（`all` 或 `sp,su,au,wi` 组合），`gentle` 标记是否适合老人小孩。

## 数据来源

- **营养标准**：中国营养学会《中国居民膳食指南（2022）》
- **价格基准**：成都农产品中心批发市场 2026-11 行情 + 成都市发改委零售监测，元/500g
- **做法**：《四川烹饪》及川菜师傅口诀，其余为家常做法实测
